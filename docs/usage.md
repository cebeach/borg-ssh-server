# Usage

The image is hosted on docker hub:
https://hub.docker.com/repository/docker/chadly314/borg-ssh-server/general

The following bind mounts are required to run this container:
/repos: the borgbackup repository root directory
/etc/ssh/host_keys: a directory containing a ssh_host_ed25519_key/ssh_host_ed25519_key.pub keypair generated by ssh-keygen
/home/borg/.ssh/authorized_keys: authorized_keys file which restricts command usage; see config/authorized_keys_template

Build an image:
scripts/build.sh

Remove image and remove build cache:
scripts/clean.sh

Metadata:
scripts/config.sh

Stop running container and remove it:
scripts/stop.sh

Start container:
scripts/start.sh

Start container in interactive mode with /bin/bash as PID 1 for debug:
scripts/interactive.sh

Publish image to docker hub:
scripts/publish.sh
